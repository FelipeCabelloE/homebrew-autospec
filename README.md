# Felipecabelloe Autospec

## How do I install these formulae?

`brew install felipecabelloe/autospec/<formula>`

Or `brew tap felipecabelloe/autospec` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "felipecabelloe/autospec"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
